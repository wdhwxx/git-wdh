## 一、目标与范围

- **目标**：依托掘金量化仿真柜台 + 现有鲲鹏量化系统（SIM 模式），搭建可复用的量化策略仿真模拟盘，打通「回测 → 仿真 → 实盘迁移」链路。
- **范围**：沪深A股、商品期货、股指期货仿真；API 仿真与手动仿真；多账户、跨市场、跨品种。
- **KPI**：试运行前环境100%就绪；账户就绪后 ≤1 个月完成试运行；首批 ≥3 只策略完成仿真验证；仿真—实盘零误接入；报备留痕率100%。

## 四、验收要点（T1-T8 分级速览）

- **A 类（代码/SIM 层，现在即可验）**：T2 重复信号拦截幂等、T4 资金不足业务拒单不 failover、T5 通道故障 failover 冷却切回、T6 隔夜回报防未来 —— 走 `pytest` 单测，须全过。
- **B 类（需真实 QMT 环境）**：T1 信号→风控→下单→委托编号双向映射、T3 断线重连仅补发未成交、T7 真实环境链路。
- **C 类（需真实资金/连续运行）**：T8 全天运行（1日）+ 小额真钱验证。
- **铁律**：回测与实盘参数一致；全程防未来函数；仿真—实盘零误接入；实盘迁移双人复核。

## 五、主要风险与注意

- 仿真与实盘差异（滑点/撮合）→ 实盘前小资金验证、监控绩效偏差。
- 行情/网络依赖 → 保障订阅稳定，配套异常预案。
- 串户/误操作 → 隔离设计 + 双人复核。
- 合规 → 跟踪程序化交易监管要求，报备与留痕。
- **占位项**：【单位名称】【编制日期】【期初资金】【阈值】等按实际核定后填充。
