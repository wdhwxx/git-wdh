## 3. 监控端已具备能力（代码级核验）

| 模块 | 能力 | 关键点 |
|------|------|--------|
| `monitoring/alerting.py` | AlertManager：分级告警、升级（check_escalations）、去重、多通道、回调 | 已接入 run_实盘入口 `setup_monitoring_linkage` |
| `monitoring/metrics_collector.py` | 事件采集（`collect_from_event_bus` L744） | **仅订阅**：DATA_QUALITY_DIRTY / PIPELINE_COMPLETE / RISK_PAUSED / RISK_RESUMED；**未订阅交易事件**（→A-3 直接对应） |
| `monitoring/health_check.py` | L0 基础设施健康巡检（add_check 动态注册，磁盘/进程/数据源/券商连接） | 已有 check_data_source 等 |
| `monitoring/data_quality_explorer.py` | 数据质量探查（13 方法，纯 Python 数据层） | 已从 web/dashboard 下沉 |
| `live/scheduler.py` | HealthPatrol 巡检 + 日报 + 盘后对账 cron（reconcile_cron）+ 告警升级周期 + 月频模型治理 | KP-P5-03/04/11 已落地 |

**核心缺口（与施工清单的映射，全部为代码级核验结论）**：
1. **交易事件未接入**：`EventType` 8 类（ORDER_SUBMIT / FILLED / PARTIAL / CANCELLED / REJECTED / POSITION_UPDATE / SIGNAL / SYSTEM_ERROR）**已定义但引擎未发布、监控未订阅** → 清单 **A-3** 直击项（M1-Min 保底项）。
2. **链路 id 四元组缺失**：`Event` 基类仅 `event_id/timestamp/source/priority`，无 `signal_id/order_id/trade_id/event_ts` → 清单 **BASE-4**。
3. **行情活性/延迟 SLI 无** → **A-4 / B-4**。
4. **实时对账无事件驱动**：现有 `reconcile_vs_broker` 为盘后 cron，无每次 FILLED/POSITION_UPDATE 触发的实时核对 → **A-7 / B-1**。
5. **持仓/资金/PnL 时序落库无**：`metrics_history` 表不存在，权益曲线不可回放 → **BASE-2 / B-2**。
6. **限额使用率 / 拒单率 / 保证金占用指标未采集** → **B-3 / B-5 / B-9**。

## 4. 策略风格画像（R-05：可选项启用决策依据）

对现有 7 个已注册策略逐一判定风格档：

| 策略 | 实现文件 | 判定风格 | 依据 |
|------|----------|----------|------|
| ma_cross | strategies/ma_strategy.py | 中低频因子 | 均线交叉，bar 级信号 |
| rsrs | indicators/rsrs.py | 中低频因子 | RSRS 动量择时，bar 级 |
| momentum | strategies/momentum_strategy.py | 中低频因子 | 动量，bar 级 |
| mean_reversion | strategies/mean_reversion_strategy.py | 中低频因子 | 均值回归，bar 级 |
| multi_factor | strategies/multi_factor_strategy.py | 中低频因子 | 多因子合成，bar 级 |
| grid | strategies/grid_strategy.py | 区间震荡（低频网格） | 网格交易，非做市 |
| kunpeng（主策略） | strategies/kunpeng_strategy.py | 中低频因子/趋势 | 鲲鹏壹号，因子+趋势 |

**画像结论**：当前系统为**中低频因子/趋势型主导**，未涉及日内、高频做市。
**对可选项的意义（R-05 决策矩阵）**：
- **A-14 订单簿深度/价差质量**：中低频因子档 = **关闭**（非必开）。
- **C-11 数据血缘元数据**：中低频因子档 = **远期**（非必开）。
- 若未来引入日内/高频策略，需按画像矩阵重新评估启用上述可选项。
