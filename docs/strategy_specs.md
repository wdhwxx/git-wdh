# Pythonwdhmm 鲲鹏量化交易系统 — 策略规格文档

## 1. 核心策略：RSRS阻力支撑相对强度

### 1.1 策略原理

RSRS（Resistance Support Relative Strength，阻力支撑相对强度）通过对每日最高价与最低价进行线性回归，用回归斜率衡量市场趋势强度。斜率标准化后超过阈值产生买卖信号。

### 1.2 计算方法（严格无未来函数）

步骤 1：取前 N 日最高价和最低价（N=18，不含当日）
high [i-N:i], low [i-N:i]

步骤 2：线性回归 low = alpha + beta * high
beta = slope（斜率）

步骤 3：对 beta 序列做 Z-Score 标准化（窗口 = 60）
rsrs_norm = (beta - mean (beta [-60:])) /std (beta [-60:])

步骤 4：信号判断
rsrs_norm > 0.7  → 买入信号
rsrs_norm < -0.7 → 卖出信号
其他             → 无信号

### 1.3 防未来函数铁律

| 铁律 | 具体要求 | 违反后果 |
|---|---|---|
| 指标计算不含当日 | iloc[i-period:i]，不包含第i根K线 | 回测收益虚高，实盘失效 |
| 移动止损先检查后更新 | 先判断是否触发止损，再更新止损价 | 止损逻辑失效 |
| 信号T日收盘→T+1开盘 | T日收盘产生信号，T+1开盘价成交 | 未来函数 |
| 因子仅用历史数据 | 股票池筛选只用信号日之前的数据 | 选股结果包含未来信息 |

### 1.4 策略参数（阶段六最优）

| 参数 | 值 | 说明 | 调优范围 |
|---|---|---|---|
| period | 18 | RSRS回归周期 | 10-25 |
| norm_window | 60 | 标准化窗口 | 30-120 |
| buy_threshold | 0.7 | 买入阈值 | 0.5-1.0 |
| sell_threshold | -0.7 | 卖出阈值 | -1.0--0.5 |
| take_profit_pct | 0.20 | 目标止盈+20% | 0.10-0.30 |
| stop_loss_pct | 0.15 | 止损-15%（0=不启用） | 0-0.20 |

## 2. 股票池筛选：三因子交集

### 2.1 三因子定义

| 因子 | 计算方法 | 窗口 | 选股逻辑 |
|---|---|---|---|
| 波动率因子 | 20日收益率标准差（年化） | 20日 | 取前1/3低波动率 |
| 动量因子 | 60日累计收益率 | 60日 | 取前1/3高动量 |
| 价格因子 | 最新收盘价 | 当日 | 取前1/3高价股 |

### 2.2 筛选流程（严格无未来函数）

1. 获取全市场股票列表（约 820 只）
2. 对每只股票：
a. 取信号日之前 20 日数据 → 计算 20 日波动率（pct_chg/100 的标准差）
b. 取信号日之前 60 日数据 → 计算 60 日动量（累计收益率）
c. 取信号日收盘价 → 价格因子
3. 各因子分别取前 1/3
4. 取三个因子的交集 → 三因子交集股票池
5. 排除：ST 股、停牌股、上市不足 60 天新股、日均成交量 < 100 万股

### 2.3 因子计算注意事项

- **pct_chg是百分比格式**：计算波动率时必须先除以100
  - 正确：df['pct_chg'].rolling(20).std() / 100
  - 错误：df['pct_chg'].rolling(20).std()（结果大100倍）
- 因子计算仅用信号日之前的历史数据，禁止使用未来数据
- 股票池在信号日收盘后确定，T+1日开盘执行交易

### 2.4 三因子 vs 单因子对比

| 股票池 | 样本数 | 平均收益 | 正收益占比 |
|---|---|---|---|
| 三因子交集 | 49 | +87.38% | 65.31% |
| 低波动率单因子 | 234 | +63.65% | - |
| 高价股单因子 | 234 | +56.46% | - |
| 高动量单因子 | 234 | +53.97% | - |
| 全市场基准 | 703 | +41.51% | - |

## 3. 交易规则

### 3.1 买入规则

条件（全部满足）：

1. 股票在三因子交集股票池中
2. RSRS_norm > 0.7（买入信号）
3. 当前持仓数 < 5（最多持有 5 只）
4. 单只股票仓位 ≤ 20%
5. 非涨停（涨停无法买入）
6. 非停牌
7. 非 ST 股

执行：

- T 日收盘后产生买入信号
- T+1 日开盘价成交
- 买入金额 = 总资金 × 20%（单票最大仓位）
- 扣除佣金（万 2，最低 5 元）+ 过户费（万 0.1）+ 滑点（万 2）
- 
### 3.2 卖出规则

条件（满足任一）：

1. RSRS_norm < -0.7（卖出信号）
2. 持仓收益 ≥ +20%（目标止盈）
3. 持仓收益 ≤ -15%（止损，如启用）
4. 持仓股票跌停（无法卖出，次日继续尝试）

执行：

- T 日收盘后产生卖出信号
- T+1 日开盘价成交
- 扣除佣金（万 2，最低 5 元）+ 印花税（千 1）+ 过户费（万 0.1）+ 滑点（万 2）
- 
### 3.3 仓位管理

| 参数 | 值 | 说明 |
|---|---|---|
| 初始资金 | 100万 | 回测/实盘一致 |
| 单票最大仓位 | 20% | 每只股票最多投入20万 |
| 最多持仓数 | 5只 | 同时持有不超过5只 |
| 总仓位上限 | 95% | 留5%现金 |
| 最小交易单位 | 100股 | 1手，买入必须是100的整数倍 |

### 3.4 交易成本（A股写实）

| 费用项 | 费率 | 收取方向 | 说明 |
|---|---|---|---|
| 佣金 | 万2（0.0002） | 买卖双向 | 最低5元 |
| 印花税 | 千1（0.001） | 仅卖出 | A股标准 |
| 过户费 | 万0.1（0.00001） | 买卖双向 | 沪市收取 |
| 滑点 | 万2（0.0002） | 买卖双向 | 模拟冲击成本 |

### 4.2 回测校验清单

- LookaheadGuard.assert_pass () 必须通过
- 买入信号 T 日产生，T+1 开盘价成交
- 卖出信号 T 日产生，T+1 开盘价成交
- 涨停日不能买入，跌停日不能卖出

### 4.3 绩效指标说明
指标	计算方法	合格标准
总收益率	(期末资金 - 期初资金)/ 期初资金	> 基准收益
年化收益率	(1 + 总收益)^(252 / 交易日数)-1	> 15%
夏普比率	(年化收益 - 无风险利率)/ 年化波动率	> 0.5（当前 0.241，待优化）
最大回撤	max (峰值 - 谷值)/ 峰值	< 30%（当前 - 49%，待优化）
胜率	盈利交易数 / 总交易数	> 50%
盈亏比	平均盈利 / 平均亏损	> 1.2（当前 1.33）
正收益占比	正收益股票数 / 总股票数	> 60%（当前 65.31%）
## 5. 实盘注意事项

### 5.1 实盘运行流程
每日08:30  盘前数据更新（akshare增量下载前一日数据）
每日15:05  收盘后信号生成
           ├── 加载全市场股票数据
           ├── 三因子交集筛选股票池
           ├── 计算RSRS信号
           ├── 检查持仓止盈/止损
           ├── 生成买入/卖出信号
           ├── 生成HTML信号报告
           └── 推送消息（飞书/企业微信/邮件）
每日15:30  盘后数据更新
每日16:00  每日报告推送
5.2 实盘与回测差异处理
差异点	回测	实盘	处理方式
成交价	T+1 开盘价（确定）	T+1 开盘价（可能滑点）	实盘加滑点缓冲
涨跌停	数据中已知	实时判断	实盘实时查询涨跌停状态
停牌	数据中跳过	实时判断	实盘实时查询停牌状态
成交量	假设全部成交	可能部分成交	实盘检查流动性
数据延迟	无	akshare 有 15 分钟延迟	日线信号无影响
5.3 实盘风控规则
规则	阈值	动作
单日最大亏损	3%	停止当日交易
最大回撤	15%	清仓停止交易
单笔最大金额	20 万	拦截下单
单日最大交易次数	20 次	拦截后续下单
单票最大仓位	20%	拦截超额下单
断线超时	300 秒	强制平仓（需券商支持）
### 5.4 状态持久化与崩溃恢复

- 每次信号生成后自动保存状态到 实盘状态 / 目录
- 保存内容：当前持仓、资金状态、交易记录、策略上下文
- 程序重启后自动恢复上次状态（auto_recover_on_start: true）
- 状态文件：
  - 当前持仓.json：持仓明细
  - 资金状态.json：资金余额
  - 交易记录.csv：历史交易
  - 推送日志.log：消息推送记录

### 5.5 模拟盘验证要求

- 实盘前必须经过至少 5 个交易日的模拟盘验证
- 模拟盘信号与回测信号对比，确认一致性
- 模拟盘期间检查：数据更新、信号生成、消息推送、状态保存全部正常
- 模拟盘无异常后，方可切换到实盘模式（trade_mode: live）

## 6. 策略扩展规范

### 6.1 新增策略步骤

1. 在 myquant/strategies/ 下创建策略文件
2. 继承 BaseStrategy，实现 on_init 和 on_bar 方法
3. 使用 @register_strategy ("策略名") 注册
4. 在 config/strategy_params.example.yaml 中添加参数模板
5. 在 tests/test_strategies.py 中添加测试用例
6. 回测验证通过后，可用于实盘

### 6.2 策略代码规范

- 策略参数通过 on_init (config) 接收，禁止硬编码
- 信号通过 return Signal (...) 返回，禁止直接下单
- 策略中禁止访问未来数据（LookaheadGuard 自动校验）
- 策略中禁止直接修改持仓，由执行层处理
- 中文注释，说明策略逻辑和参数含义
