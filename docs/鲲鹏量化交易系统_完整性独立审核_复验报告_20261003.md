### 2.1 P0-01 运行时复现（审核报告最严重发现 → 本次最重要实证）

复现方式（复用项目自有测试基建）：

```
guard = LookaheadGuard()
eng = MixedBacktestEngine(config=_make_config(), strategy=_make_strategy(),
                          data=make_demo_data(n_bars=40), lookahead_guard=guard)
result = eng.run()
guard.reset()
guard.record_trade(symbol="000001.SZ", trade_date="2023-01-02",
                   signal_date="2023-01-02", price_type="OPEN", side="BUY")
eng._run_lookahead_assert()
```

复现输出（截取关键行）：

```
❌ 防未来函数校验未通过：[LookaheadError] ... 共发现 1 处违规（铁律3 ...）   ← 仅日志
assert PASSED without raising (异常被吞)
is_success = True
status = completed
```

**结论：违规真实存在 → 校验被吞 → 结果仍标记 completed 成功。审核报告 P0-01 的判断 100% 成立。** 全项目 `lookahead_guard_passed` 读取方实测：仅 `engine.py` / `mixed_engine.py` / `vectorized_engine.py` 三处写入 + `tests/unit/test_lookahead_wiring.py` 测试读取，**无任何生产读取方**。

### 2.3 P0-02 财务链路冒烟（`create_default_fetcher().get_financial_data('600519.SH')`）

- 本次环境 push2 通道 `ConnectionError`（网络阻断）→ 异常路径跳到通道② datacenter-web → **返回 1 条真实记录**（`report_date=2026-09-30`、pe 19.32、eps 35.57、`data_source=akshare_eastmoney_datacenter`）。
- **未复现 `1 [[]]` 短路**——因为短路触发条件是"push2 成功"，而本次 push2 失败。
- 结论：P0-02 是**条件性激活缺陷**：push2 不可达时（如本次）缺陷被网络故障掩盖；push2 可达（正常用户环境）时 `return []` 立即短路三通道。修复必要性不变。
