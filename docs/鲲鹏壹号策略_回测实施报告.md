## 第1章 报告概述

### 1.1 策略定位

鲲鹏起爆点策略属于中低频趋势启动型选股策略，核心目标是捕捉个股在长期横盘整理后、成交量与均线系统同步共振的起爆临界点。策略适用于A股主板及创业板，持仓周期5-20个交易日。

### 1.2 适用范围

标的池：全A股（剔除ST、停牌、上市不满60日）

数据频率：日线级别

复权方式：后复权（hfq）

基准指数：000300.SH 沪深300

### 1.3 系统架构背景

本策略运行于 Pythonwdhmm 鲲鹏量化交易系统。系统提供三模式回测引擎（event事件驱动、vectorized向量化、mixed混合模式），支持批量回测、参数优化、蒙特卡洛分析等基础设施；数据源采用 akshare 多源降级链（东财优先→腾讯→网易→新浪）；费用模型严格模拟实盘（佣金万2最低5元双向、印花税千1仅卖出、过户费万0.1双向、滑点万2）。

## 第2章 策略逻辑深度解析

### 2.1 量均线量比模块

该模块衡量当日成交量相对过去5日（不含当日）平均成交量的放大程度。当量比超过4.5倍时，表明资金突然大幅涌入，是主力启动的强烈信号。同时，统计过去6个交易日内成交量超过5/10/20/30/60日五档均线最大值的天数（鲲鹏H），若达到5天以上，说明量能持续活跃，而非单日脉冲。模块输出"近期放量门"（鲲鹏I），作为最终信号的必要条件之一。

### 2.2 均线粘合度模块

计算20日、30日、60日三条收盘价均线的最高值与最低值之比（鲲鹏M）。当该比值≤1.22时，表明中长期均线高度粘合，股价处于长期横盘整理末端，一旦突破将形成趋势性行情。粘合度越低，起爆后的空间越大。

### 2.3 起爆点一模块（鲲鹏S）

该模块捕捉 MACD 在零轴上方企稳转升的启动信号。要求 MACD 柱前三根连续递减（鲲鹏N，即 T-4~T-1 连续4日递减）、当日 MACD≥0 且首次上穿前值（鲲鹏O），并叠加以下子条件之一：EMA13 向上拐头（鲲鹏P）、|DIFF-DEA|/C<1.8%（鲲鹏Q）、MACD<0.10（鲲鹏R）。三者满足其一即触发，确保信号灵敏且不遗漏。

### 2.4 起爆点二模块（鲲鹏）

该模块在起爆点一的基础上增加价格与均线的位置确认：EMA30 不降、5日>10日>30日 EMA 多头排列刚形成（鲲鹏V）、收盘价站上30日 EMA（鲲鹏W）。同样设置三个子条件（鲲鹏X/Y/Z），分别对应价格突破、指标收敛、MACD 低位三种场景，提高信号可靠性。

### 2.5 最终信号合成逻辑

最终输出信号 =（起爆点一 OR 起爆点二）AND 近期放量门（鲲鹏I）AND 均线粘合度达标（鲲鹏M≤1.22）。三重过滤确保只在"量、价、均线"三重共振时触发，大幅降低假信号概率。信号结构树如下：

```text
最终信号 = (起爆一 ∨ 起爆二) ∧ 近期放量门(I) ∧ 均线粘合门(M ≤ 1.22)
起爆一   = 三连降转升(N∧O) ∧ (EMA13上行 ∨ MACD粘合 ∨ MACD小幅)
起爆二   = 三连降转升(N∧O) ∧ (EMA30不降 ∧ 5>10>30多头) ∧ 站上EMA30 ∧ (∨ 粘合 ∨ 小幅)
近期放量 = 近13根内出现"6根中≥5根放量" ∨ 近15根内出现量比>4.5
```

## 第3章 通达信到Python的指标转换映射

**表1　通达信函数 → pandas 映射总表**

| 通达信函数 | 语义描述 | pandas等效表达式 |
| --- | --- | --- |
| MA(X, N) | X的N日简单移动平均 | X.rolling(window=N).mean() |
| EMA(X, N) | X的N日指数移动平均（通达信递归口径） | X.ewm(span=N, adjust=False).mean() |
| REF(X, N) | X在N日前的值 | X.shift(N) |
| COUNT(X, N) | 最近N日内X为True的次数（含当日） | X.astype(int).rolling(window=N).sum() |
| BARSLAST(X) | 最近一次X为True距今的K线根数；从未发生→永不满足 | bars_since(X)：记录每根K线最近True位置，bar数=当前idx-最近True idx；无→NaN（比较恒False） |
| MAX(A, B) | A与B取较大值 | np.maximum(A, B) |
| MIN(A, B) | A与B取较小值 | np.minimum(A, B) |
| CROSS(A, B) | A从下向上穿越B | (A > B) & (A.shift(1) <= B.shift(1)) |
| ABS(X) | X的绝对值 | np.abs(X) |

注：EMA 统一使用 ewm(span=N, adjust=False)，与通达信 EMA 的递归口径一致；BARSLAST 的边界语义见第5章决策1。

def generate_signals_vectorized(self, data):
    sig = self._compute_kunpeng(data)      # 最终信号布尔序列
    target = np.zeros(n); holding = False
    for i in range(n):

            ret = close[i] / entry_close - 1

        elif holding:
            target[i] = full_shares

| 出场组 | hold_days_cap | 60 | 持有上限兜底（交易日） | [20, 120] |
| 仓位组 | max_position_pct | 0.20 | 单票最大仓位 | 固定 |
| 仓位组 | max_positions | 5 | 同时最大持仓数 | 固定 |

### 6.3 三引擎接口实现

• event模式：逐bar调用 on_bar()，通过 LookaheadGuard 严格校验数据时间戳，杜绝未来数据访问。

• vectorized模式：generate_signals_vectorized() 一次性生成全序列信号，light_lookahead_guard 校验 shift 等操作。

• mixed模式：系统 mixed_engine 采用"分块向量化生成目标持仓 + 块内事件回调撮合"，兼顾性能与真实性；策略侧提供 generate_mixed_loop() 返回目标持仓，成交由引擎按事件流程处理。

### 6.4 预热机制

策略要求至少60日历史数据用于均线计算，回测起始自动跳过前60日作为 warmup 期，不产生信号（与第5章决策2、决策10一致）。

### 6.5 信号事件日志

每次信号触发记录：时间戳、股票代码、信号类型（起爆点一/二）、触发条件明细、当时价格、成交量、均线粘合度值，便于事后归因分析。

## 第7章 回测策略设计

### 7.1 时间轴与防未来函数铁律

```text
T日收盘：用截至T日收盘的 close/volume 计算全部指标 → 生成信号（仅依赖T及更早数据）
T+1开盘：以开盘价成交（涨停不买/跌停不卖）
持仓期：逐日检查出场条件（收盘后判断，次日开盘执行）
```

全部指标 rolling/shift/ewm 只依赖当前及历史数据，天然无未来函数。回测引擎内置 LookaheadGuard（event模式）与 light_lookahead_guard（vectorized/mixed模式），回测结束强制 assert_pass()，不可跳过。

### 7.2 入场规则

• 条件：最终信号为True且当前无该标的持仓、持仓数未达上限。

• 成交：T+1开盘价买入（模拟集合竞价成交），单票≤20%仓位，100股整数倍。

• 仓位约束：单票20%、最多5只、总仓位≤95%（系统默认口径）。

• V1策略：仅尝试T+1一次；若涨停开盘买不进则放弃（后续版本可加"N日追价窗口"）。

## 第11章 风险与注意事项

1. 信号频率风险：三重条件（MACD底部形态×近期放量×均线粘合）叠加后信号可能很稀（预期全市场月均数十~数百个级别）。样本过少时夏普/回撤的统计意义有限——回测报告必须披露信号频次，交易笔数不达30笔不判定合格。

2. "接飞刀"风险：起爆一本质是"MACD见底反转"抄底逻辑，若宏观/个股基本面恶化，三连降转升可能只是下跌中继。止损必须启用（默认标准型-7%，保守-5%、激进-10%，随档位调整，回测中不得关闭）；建议先在震荡/牛市段验证，熊市段单独看回撤。

3. 过拟合风险：公式内含6+个手调阈值（4.5/13/15/1.22/0.018/0.10），过度拟合概率高。坚持第9章样本外协议；若验证段显著劣化，宁可减少阈值数量（先固定多数参数）。

4. 量能口径：量比分母为"前5日均量"，若前5日含历史天量（如放量下跌），分母被抬高→量比钝化、放量门失效。属公式固有特性，报告中如实披露。

5. 除权日量能跳变：hfq复权价下，除权日成交量可能出现非交易性放大，可能误触发A>4.5。V1接受（日线层面影响有限），如批量结果显示异常可在V1.1增加"除权日剔除"。

6. 实盘纪律：按项目待办清单要求，回测研究充分后仍需≥5个交易日模拟盘验证（run_实盘入口.py --paper-trading），信号与回测一致后才可考虑真钱小额验证。

7. 监管与诚实披露：本报告所有结论均为方案设计；任何绩效数字须以真实回测产物为准，禁止用示例数据冒充结果。

鲲鹏B:=MA(VOL,5); 鲲鹏C:=MA(VOL,10); 鲲鹏D:=MA(VOL,20); 鲲鹏E:=MA(VOL,30); 鲲鹏F:=MA(VOL,60);
