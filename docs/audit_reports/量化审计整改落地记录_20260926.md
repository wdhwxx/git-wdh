## 四、语义变更与风险提示（需用户知悉）

1. **垃圾数据清理.py --purge-results 语义统一**：原实现仅删 outputs/result_*.json 且保护报告族；现统一为共享服务 F 类（回测产物输出，含 report/equity/trades/summary/result/回测看板），与 GUI 清理面板同规则。显式传 --purge-results 才会触发，dry-run 默认不变。
2. **清理历史回测输出.py 行为不变**：仍只做 outputs 归期，不连带扫项目垃圾（构造空 junk 计划）；输出格式统一为共享服务报告格式。
3. **D7-002/003、D8-003 采用文档级声明**（审计修复动作二选一的收敛方向）：未改动引擎行为；后续如需真正接入 light guard 或回测消费 DatasetVersion，属新功能开发。
4. **D7-001 接线依赖配置**：回测端严格模式现在真正受 config 的 lookahead_guard.strict_mode 控制；若某回测配置中 strict_mode: true 而历史数据存在潜在未来函数违规，回测将抛异常而非静默记录——这是修复的预期行为，非回归。
