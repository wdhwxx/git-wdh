施工次序（验收标准 = 可观测行为变化）
P0 清账
只读+新增列/表。去重 4,377、补披露日、SAVEPOINT、残量修复。任何时刻可中止无副作用。
P1 立契约
唯一索引/三时间戳/修正台账/admission 模块/影子写入口/PIT 口径收敛。小批量先行+指纹比对。
P2 上闸门
FLAG/BLOCK 真正接入写入；废止整标的 delete+insert；收敛到唯一写入口。先影子跑误报率。
P3 时间积累
基于 ingest_time 的延迟分布建模、快照多版本化、跨源时偏监控。依赖 P0/P2 的数据积累。
