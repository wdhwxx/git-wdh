## 三、第4项 回测报告增强 — 全部成果（A-D）

### A项：蒙特卡洛分析模块 ✅
**文件：`myquant/backtest/monte_carlo.py`**（新增）
- `MonteCarloAnalyzer(n_simulations=2000, horizon_days=252, ruin_threshold=0.5, seed=42)`
  - `analyze(equity_curve) -> MonteCarloResult`
- **方法**：仅用**已实现历史收益**（pct_change）重采样引导，无未来信息
  - 收益路径模拟：对已实现收益序列有放回抽样 → 累积乘积（cumprod）
  - 回撤路径：路径累积净值 → 滚动最大值回撤（cummax）
  - 无偏标度：逐期波动率按 sqrt 折算（年化/252）
- `MonteCarloResult` 字段：final_returns / max_drawdowns / p5~p95 收益分位 /
  max_drawdown_ci_low/high / median_max_drawdown / quantile_equity(5×253分位带) /
  prob_negative / prob_ruin / n_simulations / seed
- 参数校验：n_simulations>0、horizon_days>0、0<ruin_threshold<=1
- 固定 seed 可复现；空输入返回空结果
- 净值 <30 点时 analyze 返回空（调用方自动跳过蒙特卡洛）
