## 三、B 项：流式清洗联动（事件总线）

### 交付文件
- `myquant/live/data_feed.py`（新增 `attach_event_bus` + `_RealtimeEventBridge`）
- `tests/_verify_realtime_event.py`（72 项验证）

### 核心设计（4 项加精优化）
1. **窗口聚合**：同 `(symbol, dirty_type)` 在 `aggregate_window`（默认60s）内合并为一条事件（bad_count/total_count 累加），窗口翻转才发布——避免事件风暴/告警风暴
2. **连续阈值升级**：严重类型（OHLC非法/负价/负量/时间戳无效/缺symbol）连续 ≥`critical_after`（默认3）次才 `critical`，单次仅 `warning`——过滤瞬时抖动，避免误触发风控暂停
3. **全局单例默认挂载**：`attach_event_bus(event_bus=None)` 自动用 `get_event_bus()`，一行接入
4. **线程安全 + clean streak**：聚合/计数加锁，发布在锁外；`on_clean` 清零连续计数 + clean streak 观测；`disconnect` 时 `flush_all` 补发

### 事件字段
- `dirty_type`：推断对齐任务6 14项 `DirtyDataType` 枚举
- `severity`：critical（连续≥N次严重类型）/ warning（单次或跳变/量异常）
- `source="live"`（区分离线清洗 `data_clean`）、`source_step="realtime_feed"`
- `bad_count` / `total_count`（窗口累计）、`errors`、`record`（原bar）

### 联动自动生效（零改动三处订阅方）
- 任务10 **AlertManager**：`subscribe_to_event_bus` → 收到事件 → 分级告警（critical→CRITICAL通道）
- 任务11 **MetricsCollector**：`data_quality_dirty_count` / `dirty_type_count` / `total_records` 指标自动更新
- 任务12 **RiskManager**：严重脏数据 → 自动暂停策略（任务12 已闭环验证）

### 验证结果
- 72/72 全过（含 AlertManager 告警联动、MetricsCollector 指标联动、8线程并发安全、故障隔离）

## 四、C 项：引擎实时驱动

### 交付文件
- `myquant/live/engine.py`（7 处改造）
- `tests/_verify_realtime_engine.py`（56 项验证）

### 核心改造（4 项加精优化）
1. **start() 实时模式自动启动后台轮询**：`feed.start(poll_interval=realtime_poll_interval)`；日线模式**保持不自动启动**（兼容 LiveScheduler 手动驱动，零破坏）
2. **频率自适应**：`_dict_to_bar` 不再硬编码 `DAILY`，`_infer_bar_frequency` 映射 `MINUTE_1/5/15/30`、`HOUR_1`、`DAILY`
3. **_validate_bar_time 双重保护**：实时 `≤now+5s`（与 data_feed 容忍度对齐）+ 时间单调（`bar.timestamp > 最后一根`，防旧快照晚到/重复）
4. **_warmup_history 历史预热**：频率自适应（分钟级优先 `stock_zh_a_hist_min_em`，失败降级日线）+ `clean_bar_records` 清洗过滤；策略启动即有足够窗口（如MA20），不会恒"数据不足"

### 其余改造
- `pause()`→`feed.stop()`（节能）、`resume()`→`feed.start()`（恢复）
- `stop()` 补 `feed.disconnect()`（原只 stop 不断开）
- 构造参数：`realtime_poll_interval=3` / `warmup_bars=60` / `enable_warmup=True`

### 验证结果

## 五、D 项：中文入口脚本

### 交付文件

### 核心能力
- 串起 A+B+C 完整闭环：实时行情源 → 流式清洗+事件总线 → 引擎自动轮询 → 策略信号 → 风控 → 券商模拟撮合 → 成交回报
- 12 项命令行参数：`--source` / `--frequency` / `--symbols` / `--poll-interval` / `--mock-step` / `--warmup-bars` / `--no-warmup` / `--event-bus/--no-event-bus` / `--duration` / `--capital` / `--broker`

### 快速使用
```bash
# 离线演示（默认，确定性模拟实时源）
python scripts/实时行情驱动.py

# 腾讯真实行情（交易时段，需网络）
python scripts/实时行情驱动.py --source realtime --symbols 000001.SZ,600519.SH --poll-interval 3 --duration 120

# 双券商模拟
python scripts/实时行情驱动.py --broker dual --duration 60
```

### 运行特性
- 默认 `realtime_mock` 离线可演示（mock step=10s + poll=1s → 约7秒产第一根1m bar）
- 短周期双均线策略（short=2/long=4，适配实时bar数量少）
- 信号/成交实时打印 + 每秒状态行 + 最终账户/交易/事件总线/行情源健康报告 + 链路验证断言
- `--duration` 运行时长（默认30秒，0=无限）+ Ctrl+C 优雅停止

### 券商模式说明
- `--broker paper`（默认）：PaperBroker 本地模拟撮合
- `--broker qmt / ptrade / dual`：需券商终端环境（迅投QMT/恒生Ptrade客户端+SDK），当前为 SIM 模拟桩（PaperBroker 替代），真实接入待环境就绪后完成
