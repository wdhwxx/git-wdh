### 4.7 完整自动联动链路

```
清洗流水线 / 实盘数据流
    ↓ 发布 DataQualityEvent / PipelineCompleteEvent / QualityAlertEvent
EventBus
    ├─ RiskManager.subscribe_to_event_bus()  ← 任务12
    │   ├─ 脏数据严重 → _pause_for_data_quality() 暂停策略
    │   └─ _check_auto_resume() 质量恢复 → 自动恢复
    │       ↓ 发布 StrategyPauseEvent (RISK_PAUSED / RISK_RESUMED)
    │       ├─ AlertManager.handle_strategy_pause_event()  ← C项
    │       │   ├─ 全局暂停 → CRITICAL 告警
    │       │   ├─ 单标的暂停 → ERROR 告警
    │       │   └─ 恢复 → INFO 告警
    │       └─ MetricsCollector.collect_from_strategy_pause_event()  ← D项
    │           ├─ risk_pause_total (pause_level/symbol)
    │           ├─ risk_resume_total (pause_level/symbol)
    │           └─ risk_paused (GAUGE, 全局暂停 symbol="ALL")
    └─ 实盘引擎 / API 可按需订阅 RISK_PAUSED/RISK_RESUMED 事件

Prometheus / Grafana → GET /metrics → to_prometheus()
```

### 4.8 为实盘无缝对接预留
- **事件总线解耦**：RiskManager 发布事件，不依赖任何消费方；实盘引擎/API/Web 可任意订阅暂停/恢复事件
- **全局暂停归一**：symbol 标签统一为 "ALL"，防标签爆炸（实盘海量标的）
- **自动恢复可配置**：`auto_resume_enabled=False` 可退回人工确认模式，实盘运营可按需开关
- **仅基于已发生事件**：自动恢复判定只用已发生的事件流，不预测未来质量，严格防未来函数
- **指标全链路**：暂停/恢复/当前状态均有指标，可直接对接 Prometheus 告警规则与 Grafana 大盘

## 六、关键设计决策

### 1. 暂停/恢复事件经事件总线解耦发布
- RiskManager 只负责判定暂停/恢复并发布 `StrategyPauseEvent`，**不 import 任何 monitoring 模块**
- AlertManager / MetricsCollector / 实盘引擎 / API 各自按需订阅
- 新增消费方无需修改 RiskManager，符合开闭原则，为实盘多通道通知预留

### 2. 告警分级映射（C项）
- 全局暂停 → CRITICAL（系统级风险，必须人工关注）
- 单标的暂停 → ERROR（局部风险）
- 恢复 → INFO（仅记录，不打扰）
- 映射常量化：`STRATEGY_PAUSE_ALERT_LEVEL_MAP`，后续可扩展（如新增 pause_level 档位）

### 3. 全局暂停的 symbol 标签归一为 "ALL"（D项）
- 全局暂停时若逐个标的上报，会刷爆 Prometheus 标签组合（上限保护 max_metrics_per_name=1000）
- 归一为 "ALL" 后指标维度稳定可查

### 4. 自动恢复判定（E项）——严格禁用未来函数
- **只基于已发生的事件流判定**：质量等级∈恢复等级 且 占比<阈值，连续 N 次才恢复
- 不使用任何对"未来数据质量"的预测/推断
- 坏信号立即重置计数，避免假恢复
- `consecutive_good_required=1` 为最宽松默认，可调严

### 5. 防未来函数（铁律4）
- 暂停判定只用已发布事件的脏数据占比/等级/严重级别
- 自动恢复判定只用已发生事件的质量信号
- 所有时间用 `extra["current_time"]` 或事件自带时间戳，无任何预测方法/属性
- 源码中无 predict/forecast/future 关键词

### 6. 为实盘无缝对接预留
- 实盘数据流发布 DataQualityEvent → RiskManager 自动暂停 → 事件总线广播 → 告警/指标/引擎全部联动
- 自动恢复可配置阈值，实盘运营可调；`auto_resume_enabled=False` 退回人工确认
- 指标全链路可上 Prometheus/Grafana，风控状态对实盘可观测
