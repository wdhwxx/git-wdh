### 4.2 存储布局（对齐任务14 数据集版本管理成熟模式）

```
datasets/models/{model_name}/versions/
├── index.json            # 版本索引（head.active/head.latest/last_rollback/versions 摘要）
└── v{n}/
    ├── model.pkl         # 模型工件（pickle 标准库序列化，不绑定 ML 框架）
    └── metadata.json     # ModelVersion 版本元数据
```

模型名自动目录安全化（`_safe_name`，非法字符替换为下划线）。

### 4.3 ModelVersion 元数据结构（metadata.json）

| 字段 | 说明 |
|------|------|
| model_name / version | 模型名 / 版本号（自增） |
| model_type | 模型类型（type(model).__module__ + . + __name__） |
| artifact / checksum | 工件文件名 / sha256 完整性校验 |
| created_at / source | 创建时间 / offline（离线训练）/ live（实盘） |
| feature_config_hash | 训练特征配置 hash（FeatureConfig JSON sha256，训练/推理特征绑定） |
| feature_columns | 训练特征列名（与任务18 对齐，推理必须一致） |
| label_column | 标签列名 |
| train_start_time / **train_end_time** | 训练数据起止（**train_end_time 防未来：推理只使用 <= 截止数据**） |
| metrics / hyperparameters | 评估指标 / 超参数（任务20 训练产出） |
| status | active（当前生效）/ archived（归档） |
| parent_version / description | 派生链 / 描述 |

### 4.4 ModelRegistry 方法清单

| 方法 | 功能 |
|------|------|
| `register_model()` | 注册模型（版本自增 max+1 / 工件落盘 / checksum / 索引双写 / active 默认最新） |
| `list_models()` / `list_versions()` | 模型列表 / 版本列表（倒序摘要） |
| `get_model_info()` / `get_model_metadata()` | 版本信息（默认 active）/ 完整元数据 |
| `load_model()` | 加载模型对象（**checksum 完整性校验**，篡改 → ModelIntegrityError） |
| `activate_version()` | 实盘热切换 active 版本（旧 active 自动归档） |
| `get_active_version()` / `get_latest_version()` | 当前 active / 最新版本 |
| `rollback()` | 回滚到前一版本（last_rollback 顶层记录；无更早返回 None） |
| `delete_version()` / `delete_model()` | 删除版本（head 自动回退）/ 删除整个模型 |
| `verify_model()` | checksum 完整性校验 |
| `get_summary()` | 注册表摘要 |

### 4.5 关键设计

1. **复用任务18**：`feature_config_hash`（FeatureConfig JSON hash）+ `feature_columns`（FeatureEngine 预演 40 列）→ 模型与训练特征绑定
2. **模型工件 pickle 序列化**：任意可 pickle 模型对象（任务20 训练产出直接注册），不绑定 sklearn/joblib
3. **并发安全**：线程锁 + 跨进程文件锁（实盘多进程预留，对齐任务14）
4. **异常体系**：ModelRegistryError 基类 + ModelNotFoundError / ModelVersionNotFoundError / ModelIntegrityError

### 4.6 防未来函数（铁律4）

- `train_end_time` 记录训练数据截止时间 → 任务21 推理服务校验"只用 <= 训练截止数据"
- 本模块无任何预测方法/属性（源码扫描通过）
- 无硬编码未来日期
- `load_model`/`verify_model` checksum 完整性校验（工件篡改可检出）

### 4.7 修复的 2 个真实缺陷

1. **feature_columns 解析**：`feature_columns` 是 FeatureEngine 属性而非 FeatureConfig 属性 → 修复为 `FeatureEngine(config).feature_columns` 预演（40 列正确绑定）
2. **last_rollback 写错层级**：误写入 head 内 → 修复为 index 顶层（对齐任务14 结构，get_summary 读取正常）

### 4.8 为实盘无缝对接预留（任务21-23 实盘增强前置）

- **active 热切换**：实盘模型不停机切换（activate_version，推理服务下次加载即用新 active）
- **多版本并存**：A/B 测试、快速回滚（rollback）
- **source 区分 offline/live**：实盘在线学习/微调版本独立建模
- **与任务18 衔接**：训练特征配置持久化 → 注册时绑定 feature_config_hash + feature_columns

## 六、关键设计决策

### 1. 存储布局对齐任务14
- datasets/models/{name}/versions/{index.json + v{n}/model.pkl + metadata.json}
- index.json 结构：model_name/updated_at/head{active,latest}/last_rollback/versions 摘要
- checksum（sha256）+ 索引双写 + 原子写

### 2. 与任务18 特征绑定
- feature_config_hash：训练配置 JSON sha256 → 模型与训练特征配置绑定
- feature_columns：FeatureEngine 预演 40 列 → 推理必须一致（杜绝训练-推理偏移）

### 3. 模型工件不绑定框架
- pickle 标准库序列化任意模型对象（任务20 训练产出直接注册）
- load_model 从本地受控目录加载（不加载外部不可信 pkl）

### 4. 并发安全
- 线程锁（RLock）+ 跨进程文件锁（file_lock）
- 实盘多进程场景下 register/activate/rollback/delete 安全

### 5. 防未来函数
- train_end_time 训练数据截止记录（推理只用 <= 截止数据）
- 无预测方法 / 无硬编码未来日期 / checksum 完整性校验

### 6. 为实盘无缝对接预留
- active 热切换 / 多版本并存 / source 区分 offline/live / 派生链 parent_version
