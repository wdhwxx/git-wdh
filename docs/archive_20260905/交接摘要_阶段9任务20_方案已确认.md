## 二、任务20 已交付（ml/training_pipeline.py 训练流水线）

> 方案此前已确认，本次已实现并验证通过（99 项）。

### 已实现核心
**① 内置 numpy 模型（零额外依赖，可插拔）**
- `LinearRegressor`：岭回归（正规方程 `(XᵀX+λI)⁻¹Xᵀy`，含 L2 防奇异矩阵），接口 fit/predict/get_params
- `LogisticRegressor`：逻辑回归（梯度下降二分类，内置特征标准化 + 数值稳定 sigmoid），接口 fit/predict/predict_proba/get_params
- `model_factory(label_type, model=None, **hyperparams)`：可插拔，自定义模型（fit/predict）直接传入；支持 str / FeatureConfig / dict 三种配置

**② 时间序列切分（防未来核心）**
- `time_series_split(timestamps, train_ratio, strict_split, horizon)`：绝不随机（argsort 稳定排序），按时间升序切 train/valid
- `strict_split=True`：验证集跳过 horizon 个样本缓冲 → 防标签重叠（训练集标签时段不落入验证集）

**③ 评估指标（numpy 手写）**
- 回归 `regression_metrics`：MSE / RMSE / MAE / R²
- 分类 `classification_metrics`：accuracy / precision / recall / F1

**④ 训练注册闭环**
```
run() → build_dataset(FeatureEngine) → 时间序列切分 → 训练(model_factory)
      → 验证集评估 → ModelRegistry.register_model
      （绑定 feature_config_hash / feature_columns / train_end_time / metrics / hyperparameters / source）
```

**⑤ TrainingResult**：model / version / metrics / train_start/end / n_train/n_val / feature_columns / feature_config_hash / source / training_seconds / label_type

**⑥ 实盘对接**：`retrain()` 基于最新版本重训（parent_version 版本链，实盘定期更新模型）

### 本次实现中修复的 2 个真缺陷（已含在 99 项验证）
1. `model_factory` 传 dict 配置时未读取 `label_type` → 已支持 dict（`.get("label_type")`）
2. `run(label_type="direction")` 覆盖时数据集标签仍为连续收益（未切换 0/1）→ 已按生效 label_type 构建数据集并注册对应配置（`dataclasses.replace`）

### 已实现核心

- **`predict_realtime(data, model_name, ...)` 实时预测**：最新 bar 增量特征（compute_incremental）→ 逐 bar 预测（实盘每收到新 bar 调用一次，与训练特征逐列一致）
- **特征列对齐校验**：推理特征列与训练 `feature_columns` 严格一致（`_build_engine` / `_require_columns`），不一致抛 `FeatureMisalignmentError`（防训练-推理偏移）

- **InferenceResult**：predictions / timestamps / probabilities / model_name / version / model_type / label_type / feature_columns / train_end_time / source；to_frame() / to_dict()
- **异常类**：InferenceError / FeatureMisalignmentError / ModelNotReadyError

### 防未来核心保证（源码级，验证覆盖）
- 推理路径只调 `compute_features` / `compute_incremental`，**绝不调用 build_dataset / generate_labels**（标签引用未来，禁止进入推理）
- 无 `shift(-`（未来引用）、无随机函数、无硬编码未来日期

## 四、任务22 已交付（live/scheduler.py 定时任务/巡检/日报）

> 本次新开发，已验证通过（127 项）。

### 已实现核心
- **`CronExpression` 轻量 5 字段 cron 解析**：分/时/日/月/周，支持 `*` / `*/n` / `a,b,c` / `a-b` / `a-b/n`，POSIX 日/周 OR 语义，周 7 归一为 0；`match()` 匹配 + `next_after()` 推算下次触发 + `next_timestamp()` 时间戳封装
- **`ScheduledTask` / `LiveScheduler` 定时任务调度器**：
  - `add_interval_task()`（固定间隔，可 run_immediately）+ `add_cron_task()`（cron 表达式）
  - 后台守护线程逐 tick 派发到期任务；**异常隔离**（单任务失败不中断调度）、**超时保护**（守护线程 join 超时标记 TimeoutError）、**认领防重派发**（next_run 置 inf → 重排）
  - `start/stop/pause/resume` / `run_task_now` / `run_due_tasks` / `remove_task` / `enable/disable` / `run_once` 自动禁用
- **`HealthPatrol` 健康巡检器**：引擎/行情源/券商/持仓/风控 5 项内置检查（duck-typing，缺失标记 down）+ 自定义检查项 `add_check`；输出每项 healthy/degraded/down + 汇总；引擎 RUNNING+0错误→healthy、未运行→degraded、ERROR→down
- **`DailyReport` 每日报告生成器**：汇总引擎统计/账户/持仓明细/巡检健康/汇总指标，输出 dict + Markdown + JSON 落盘 `outputs/daily_reports/{日期}_日报.md/.json`；持仓字段对齐真实 Position（avg_cost/cost_value/market_value）
- **`attach_engine()` 实盘便捷挂载**：一行注册巡检（默认 60s interval）+ 收盘日报（默认 `"30 15 * * 1-5"` cron）

### 防未来核心保证（源码级，验证覆盖）
- 调度触发仅依据当前系统时钟（time.time()），next_run 由当前时间推算，无任何市场预测
- 巡检/日报只读取"已发生"的引擎/持仓/成交状态，日报日期取生成当日
- 源码扫描：无预测未来专用方法（predict_future/forecast）、无硬编码未来日期

### 本次实现中修复的 3 个真缺陷（已含在 127 项验证）
1. 任务执行错误未累计到调度器 `total_errors`（只记 task.error_count）→ 已同步累计
2. 自定义检查项被以带参方式调用（`func(comp)`）导致 TypeError → 已改内置带参/自定义无参两种调用约定

**为什么不合并进 `数据清洗集成验证.py`：**
1. benchmarks 是性能测试，结果受机器负载影响（同机两次可能差30%），与功能断言的确定性不兼容
