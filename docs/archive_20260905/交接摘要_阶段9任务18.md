### 4.2 核心设计（三件套）

**FeatureConfig 特征配置（训练/推理共用）**
- JSON 可序列化：`to_dict()/from_dict()/to_json()/from_json()` —— 训练配置与实盘推理共用同一份，**杜绝训练-推理偏移**
- 字段：horizon(标签未来期数=5) / label_type(return/direction) / price_col / return_windows(1,5,10,20) / rolling_windows(5,20,60) / momentum_windows(5,20) / indicator_configs(10项指标) / derived_features / min_periods(30)
- `max_lookback` 属性：最大回看窗口（增量推理需缓存历史 bar 数）

**FeatureEngine 特征引擎**
| 方法 | 功能 |
|------|------|
| `compute_features(data)` | 批量特征计算：40特征列，严格因果 trailing 滚动窗口，复用 indicators |
| `generate_labels(data, horizon, label_type)` | 标签生成：forward_return（未来N期收益）+ direction（涨跌二分类），仅训练集使用 |
| `build_dataset(data)` | 特征+标签对齐 → FeatureDataset（丢弃无标签尾部，X/y/timestamps JSON安全） |
| `compute_incremental(data, lookback)` | 实盘增量特征：默认全量从起点计算，与训练最后一行**逐列精确一致** |
| `lookahead_guard(engine, data)` | 防未来断言：截断重算一致性验证 |

**FeatureDataset 特征数据集**
- X（特征矩阵，无 NaN）/ y（标签）/ timestamps / feature_columns / label_column
- `to_json()` 序列化（NaN→None，JSON 安全），供任务20训练/任务21推理

### 4.3 特征因子清单（40 列）

**价格衍生（trailing）**
- return_1/5/10/20：多期收益（close.pct_change(periods=n)）
- log_return_1：对数收益
- rolling_mean/std/max/min_5/20/60：滚动统计
- momentum_5/20：动量（close/close.shift(n)-1）

**技术指标（复用 myquant/indicators）**
- sma_20_sma / sma_60_sma / ema_12_ema / ema_26_ema / rsi_14_rsi
- macd_dif / macd_dea / macd_macd_hist / kdj_k / kdj_d / kdj_j
- atr_14_atr / bb_mid / bb_upper / bb_lower / bb_bandwidth / bb_percent_b / vol_20_volatility

**派生特征**
- sma_gap：sma_20/sma_60 - 1（均线间距）
- atr_norm：atr/close（ATR 归一化）
- bb_width：(bb_upper-bb_lower)/bb_mid（布林带宽比）

### 4.4 防未来函数（铁律4，本任务核心）

1. **特征严格因果**：全部 trailing 窗口（pandas rolling/pct_change/shift(n) 只使用 ≤t 数据），t 时刻特征绝不引用未来 bar；输入自动按 timestamp 升序
2. **标签仅训练用**：`forward_return = close.shift(-horizon)/close - 1` 引用未来，但仅存在于训练目标列；`build_dataset` 丢弃无标签尾部行（最后 horizon 行不参与训练）
3. **lookahead_guard 显式验证**：对每行截断重算特征，断言与全量计算一致（正常引擎=True；monkeypatch 注入 shift(-1) 未来泄露特征 → 检出=False）
4. **篡改未来验证**：篡改第 100 行之后 close 为 99999 → 第 50 行特征不变（6列验证），最新行受影响（篡改生效）
5. **源码扫描**：无预测方法 / 无硬编码未来日期
6. **input 约束**：仅读 processed 清洗后数据（Bar 列表或 DataFrame），禁读 raw（文件头声明 + bars_to_df 文档约束）

### 4.5 为实盘无缝对接预留（任务22-23 实盘增强前置）

- **compute_incremental 与训练精确一致**：默认全量数据从起点计算，`abs(inc[c]-last[c])<1e-9` 逐列断言通过；Bar 列表与 DataFrame 双输入等价
- **FeatureConfig JSON 序列化**：训练配置持久化后实盘推理 `from_json` 复用同一配置，特征逐列一致（杜绝训练-推理偏移）
- **特征列名固定**：训练/推理完全一致
- **关键修正**：递推指标（EMA/RSI/MACD/KDJ）截断窗口后递推起点变化会产生 warmup 偏移 → compute_incremental 默认全量从起点计算解决；`lookback` 参数仅显式截断（文档注明仅 trailing 统计精确）

## 六、关键设计决策

### 1. 特征三件套（FeatureConfig/FeatureEngine/FeatureDataset）
- FeatureConfig：训练/推理共用配置，JSON 序列化，杜绝训练-推理偏移
- FeatureEngine：compute_features/generate_labels/build_dataset/compute_incremental/lookahead_guard
- FeatureDataset：X/y/timestamps，JSON 安全（NaN→None），供训练/推理

### 2. 复用 indicators（零重复造轮子）
- 10 项技术指标通过 `get_indicator(name, **params).calculate(df)` 直接复用阶段3 indicators
- 只提取指标输出列（非输入列），用统一前缀命名（sma_20_sma / rsi_14_rsi / macd_dif / kdj_k / atr_14_atr / bb_upper / vol_20_volatility）
- 指标缺失（缺 OHLC）时优雅降级：价格衍生仍可算，指标列跳过（warning 日志）

### 3. 防未来函数三层保障
- **设计层**：特征 trailing 窗口 + 标签仅训练 + build_dataset 丢弃尾部
- **验证层**：lookahead_guard 截断重算一致性（可检出未来泄露）+ 篡改未来不影响当前特征
- **扫描层**：源码扫描无预测方法/无硬编码未来日期

### 4. compute_incremental 全量一致（实盘关键）
- 递推指标（EMA/RSI/MACD/KDJ）截断窗口会有 warmup 偏移 → 默认全量从起点计算
- 与训练最后一行逐列一致（`abs(inc[c]-last[c])<1e-9`），Bar/df 双输入等价
- `lookback` 参数可选显式截断（仅 trailing 统计精确，文档注明）

### 5. 输入约束
- 仅读 processed 清洗后数据（Bar 列表 / DataFrame），禁读 raw（总图 myquant/ml/ 注释）
- 自动按 timestamp 升序（防未来：确保特征按时间因果顺序计算）
