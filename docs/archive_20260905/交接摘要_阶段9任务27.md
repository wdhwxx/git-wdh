1. **`myquant/live/brokers/manager.py`**（任务26交付，本次新增 1 方法）

## 五、关键接口速查

```python
# 双券商并行（推荐）
mgr = BrokerManager(auto_failover=True)
mgr.register_broker(QmtBroker(account_id="Q1", mode="SIM", initial_capital=1_000_000), alias="qmt", role="primary")
mgr.register_broker(PtradeBroker(account_id="P1", mode="SIM", initial_capital=1_000_000), alias="ptrade", role="secondary")
mgr.connect_all()
engine.set_broker_manager(mgr)          # 引擎统一走多券商通道

# 单券商（向后兼容，自动包装）
engine.set_broker(PaperBroker(initial_capital=200_000))

# 行情广播（引擎 on_market_data 内部自动调用，也可手动）
mgr.push_market_data("600519.SH", bar_dict)   # -> {"qmt": 成交笔数, "ptrade": 成交笔数}

# 主备切换
mgr.failover()                            # 返回新主券商 alias
mgr.health_check()["connected"]           # 默认主券商健康

# 引擎信息
engine.get_status()["broker"]             # {"mode", "primary", "broker_count", "brokers"}
engine.health_check()["broker"]           # {"primary", "brokers": {alias: hc}, "connected"}
```
