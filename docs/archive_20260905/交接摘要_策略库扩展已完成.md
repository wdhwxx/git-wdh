### A项：网格策略 ✅
**文件：`myquant/strategies/grid_strategy.py`**（name="grid"，@register_strategy）
- 固定上下界网格 + auto_grid（基于历史ATR自动计算区间）

- 区间下破止损 / 上破止盈 → 市价清仓；每格仓位 position_per_grid，A股100股整数倍

### B项：动量策略 ✅
**文件：`myquant/strategies/momentum_strategy.py`**（name="momentum"，@register_strategy）
- 动量 = close[-1]/close[-period-1]-1（trailing窗口）；定期调仓（_should_rebalance）选动量top_n
- 卖出不在池的 + 买入新入池的；等权分配 或 动量加权；单票仓位上限；min_momentum阈值过滤
- 单票止损/止盈（复用base.py工具）
- ★ F项修复防未来缺陷：新增 `_get_close_upto(context, symbol, ts)`，`_calc_momentum_scores`/`_get_latest_price` 均按 bar.timestamp 截断 context.data（原读全量最后一行=回测读到未来价）
- `get_momentum_status()` 供监控

### C项：均值回归策略 ✅
**文件：`myquant/strategies/mean_reversion_strategy.py`**（name="mean_reversion"，@register_strategy）
- 复用 indicators 模块：BollingerBands(period,std_dev) + RSI(period)（已内置防未来）
- 买入：价格<=布林下轨 AND RSI<=oversold（可关闭RSI过滤）
- 卖出：价格>=布林上轨+RSI超买 / 回归中轨平仓(exit_on_mid) / 止损 / 止盈
- 带宽保护：min_bandwidth_pct=0.5%，带宽过窄不交易

## 五、关键技术细节（下次继续时参考）

### 策略层架构（现共6个策略）
- 基类：`myquant/strategies/base.py` → StrategyBase（抽象方法 generate_signal，生命周期 on_init/on_bar/on_tick/on_stop，通用工具 check_stop_loss/check_take_profit/_should_rebalance/_get_close_series）
- 注册器：`myquant/strategies/registry.py` → @register_strategy 装饰器 + create_strategy 工厂 + discover_strategies 动态发现 + list_strategies
- 6策略：ma_cross / rsrs / grid / momentum / mean_reversion / multi_factor
- 配置文件：`config/strategy_params.example.yaml` 含全部6策略参数块（配置即参数）

### indicators 模块可用指标
- 移动平均：SMA / EMA / WMA / MACD
- 动量：ROC / MOM / RSI / KDJ
- 波动率：ATR / Volatility / BollingerBands（输出列：mid, upper, lower, bandwidth, percent_b）
- RSRS
- 所有指标继承 IndicatorBase，支持批量 calculate + 流式 update，已内置防未来函数校验

### 实盘对接要点
- 策略通过 StrategyContext 访问 data/portfolio/executor，不直接依赖引擎
- on_bar 逐根驱动（回测/实盘统一），on_tick 默认不处理（预留）
- 订单用 OrderType.MARKET 或 LIMIT，通过 context.submit_order 提交
- 持仓用 context.get_position(symbol) 查询，现金用 context.get_cash()
- 调仓类策略（momentum/multi_factor）的指标/价格读取必须按当前 bar.timestamp 截断（见第四节）
