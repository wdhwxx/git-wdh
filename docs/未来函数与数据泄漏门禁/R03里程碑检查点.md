## 3. 复核依据

1. `preprocess_panel` 的调用方 `multi_factor_strategy.py:781` 传入 `raw` 为
   `series.iloc[-1]` 逐标的取当日值拼成的**横截面面板**（index=symbol），
   `winsorize_quantile/winsorize_adaptive` 对其逐列缩尾 = 单日截面处理，无未来信息。
2. `_zscore_cross_sectional`（:747）对截面 `raw` 求 `mean/std` 属横截面标准化，
   不跨时间；`_zscore_ts_rolling`（:815）用 `rolling()` 仅历史窗口。
3. `volatility.py` 的 `_winsorize_expanding` 为扩张窗口，仅依赖历史。
4. 全库静态扫描（274 文件）R03 命中 0（对 `panel/full/all_/entire/whole` 命名接收者
   的裸聚合告警）；策略侧 7 策略 R03 告警 0。
