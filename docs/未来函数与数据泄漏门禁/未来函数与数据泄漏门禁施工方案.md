# 未来函数 / 数据泄漏门禁 — 施工方案

> 项目：Pythonwdhmm（鲲鹏量化交易系统）
> 版本：v1.0 · 2026-10-09
> 定位：基于对 `D:\Projects\Pythonwdhmm` 现有代码库的只读探查（技术栈、数据形态、存量门禁资产均已核实），针对"未来函数（look-ahead bias）与数据泄漏（data leakage）"给出可落地、可分期的工程门禁施工方案。
> 原则：**不推倒现有 guard 资产，定位为"补网 + 立规矩 + 可审计"**。

## 1. 背景与目标

### 1.1 问题定义

- **未来函数（未来函数）**：指标/信号在计算时使用了决策时点之后的数据。典型形态——同根 K 线用收盘价下单、`rolling(center=True)`、`.shift(-n)`、全序列标准化后再切片、用未来复权/财务信息修正历史价。
- **数据泄漏（data leakage）**：更宽泛的概念，含训练/验证集污染、标签泄漏、横截面泄漏（用未来全体股票统计）、幸存者偏差等。

### 1.2 门禁目标

把"防泄漏"从零散代码埋点升级为**强制、可审计、可豁免**的工程门禁体系：

1. 写代码阶段提前拦截（静态扫描）；
2. 运行时逐点拦截（现有 guard 补强）；
3. 统计层探测（shuffle-label、时间一致性）；
4. 数据层 PIT 校验（决策时点快照）；
5. 治理层闭环（红线台账、豁免流、审计报告）。

## 4. 缺口诊断（五层门禁模型）

| 层 | 现状 | 缺口（本方案补） |
|---|---|---|
| **L0 数据层** | ann_date PIT、复权/股本事件表、data_versioner | ① `processed` parquet 为"全量最终态"，**无决策时点 as-of 校验**；② 复权序列"决策时点价格语义"未显式锚定 |
| **L1 特征/因子层** | 数据指纹防缓存泄漏、IC/ICIR+经济逻辑、ML 特征截断重算 | ① **无静态 AST 扫描**；② 横截面 as-of 对齐无专门检测；③ 因子因果无统一契约 |
| **L2 模型层** | time_series_split、walk-forward、train_end_time+推理守卫 | ① **无 shuffle-label sanity test**；② 训练产物时间强校验缺失；③ 参数优化/MC 种子未统一治理 |
| **L3 执行层** | 四铁律 + 轻量 guard，覆盖面扎实 | 策略自定义**内嵌计算**不被引擎 guard 覆盖（截断重算法可推广到策略/因子） |
| **L4 治理层** | CI 强制 + audit_log 哈希链 + 架构门禁 | ① 无统一红线台账/豁免审批流；② 无泄漏审计报告产物 |

## 5. 总体架构设计

新增一个**门禁中心（`myquant/guard` 包）**，作为防泄漏的统一入口，与既有 `core/lookahead_guard`、`core/light_lookahead_guard` 并存并编排：

```
myquant/guard/
├── __init__.py          # 包导出：gate / static_scan / cross_sectional / sanity / report
├── gate.py              # 门禁中心：统一配置、Violation 结构、违规台账落库、assert_all_gates_pass()
├── static_scan.py       # 静态 AST 扫描器（L1，写代码阶段拦截）
├── cross_sectional.py   # 横截面 as-of 对齐校验器（L1）
├── sanity.py            # shuffle-label 统计探测（L2）
└── report.py            # 泄漏审计报告产物（L4）
```

- **统一配置**：从 `config/settings.yaml`（新增 `leakage_gate` 段）读取 enabled / strict / 白名单 / 豁免。
- **违规台账**：统一 `Violation` 结构，落库 `audit_log`（复用既有哈希链，保证可审计、防篡改）。
- **汇总入口**：`gate.assert_all_gates_pass()`，回测结束、训练结束、参数优化结束统一调用。

## 6. 四期施工方案

### P1 治理骨架（约 1–2 周）——先立规矩，让门禁可管理

**目标**：门禁可集中开关、违规可审计、强制项有对应测试；防止门禁被悄悄删掉而不自知。

**新增**：
1. `docs/未来函数与数据泄漏门禁/防泄漏门禁红线清单.md`
   - 泄漏类型 × 强制环节 × 验收标准 × 责任人 × 豁免流程（谁审批、落哪里、有效期）。
2. `myquant/guard/gate.py`（门禁中心）
   - 统一配置（enabled/strict/白名单/豁免）；
   - 统一 `Violation` 结构 + 违规台账落库（复用 `audit_log` 哈希链）；
   - `assert_all_gates_pass()` 汇总校验入口。

**修改**：
3. `config/settings.yaml`（新增 `leakage_gate` 配置段）
4. `.github/workflows/ci.yml`（新增"门禁台账校验" job：断言红线清单中标记"强制"的项都有对应测试/校验器存在）

**验收**：
- 门禁中心可一键启用/关闭，违规统一落 `audit_log` 可查；
- CI 台账 job：红线清单任一强制项缺失对应实现即红。

---

### P2 静态扫描 + 数据层补漏（约 2–3 周）——补最大盲区

**目标**：写代码阶段拦截泄漏模式；数据层补 PIT 快照校验。

**新增**：
1. `myquant/guard/static_scan.py`（AST 扫描器）
   - 扫描策略/因子/特征代码中的泄漏模式（规则库初稿见附录 A）；
   - 分级"阻断 / 警告" + 白名单（允许合法写法：截面排名、当日全体分位）；
   - 接 CI 独立 job（基线护栏式，新增即红）+ 本地 pre-commit hook。
2. `myquant/guard/cross_sectional.py`（横截面 as-of 对齐校验器）
   - 对候选池/三因子筛选断言"当日横截面统计只使用当日数据"；
   - 推广 features 的截断重算一致性到 `factor_engine`（新增自检模式）。

**修改**：
3. `myquant/backtest/data_loader.py`（回测数据加载增加快照校验）
   - 读取时记录文件指纹 + 版本 sidecar 对比；
   - 断言计算窗口不越界（`start_date` 之前、`end_date` 之后不参与计算）。
4. `myquant/indicators/factor_engine.py`（新增截断重算自检模式，仅对**新注册**因子强制）
5. 复权语义锚定：在因子计算处显式声明"使用 hfq 序列时，除权事件按公告日/除权日对齐，决策时点前不感知未来复权修正"，并补测试锚点。

**验收**：
- 任一新增因子/策略代码不经静态扫描与截断重算不得进入回测/实盘链路；
- 回测加载命中数据版本变更或窗口越界即告警/拦截。

---

### P3 模型层统计门禁（约 2 周）——把泄漏"测"出来

**目标**：用统计手段探测标签泄漏与时间泄漏，强制训练产物元数据。

**新增**：
1. `myquant/guard/sanity.py`（shuffle-label 统计探测）
   - 训练流水线内置"打乱标签"对照，记录 baseline 性能；
   - 模型在打乱标签下性能显著 > 阈值 → 拦截/告警（标签泄漏信号）。

**修改**：
2. `myquant/ml/training_pipeline.py`
   - 训练结束写入 `train_end_time` 时，强制校验"特征最近时间 ≤ train_end_time 且 > train_start_time"；
   - 挂接 sanity 探测。
3. `myquant/backtest/param_optimizer.py`、`myquant/backtest/monte_carlo.py`
   - 固定随机种子并写入结果 sidecar（防不可复现的过拟合结果混入审计）。

**验收**：
- 打乱标签后模型性能不归零即拦截；
- 训练产物元数据不完整（时间窗口越界/缺种子）不得注册。

---

### P4 审计收口（约 1–2 周）

**目标**：每次实验留一份可追溯的泄漏审计产物；豁免闭环。

**新增**：
1. `myquant/guard/report.py`
   - 每次回测/训练/参数优化产出 `leakage_report.json`（guard 统计 + 截断重算 + sanity + 数据版本 sidecar 摘要），与结果并排存档。
2. `tests/guard/` 专项测试包
   - `test_static_scan.py` / `test_cross_sectional.py` / `test_sanity.py` / `test_gate_governance.py`，挂 CI 强制。

**修改**：
3. `.github/workflows/ci.yml`（门禁矩阵扩展：台账校验 + 静态扫描 + sanity + 专项测试全绿）

**验收**：
- 每次实验有 `leakage_report.json` 审计产物；
- 豁免台账含 ID/原因/有效期，过期豁免被门禁中心拦截；
- 门禁矩阵 CI 全绿。

## 10. 附录 A — 静态 AST 扫描规则库（初稿）

> 供 P2 落地参考，按优先级排序。规则命中分"阻断（high）"与"警告（medium）"两档。

| 规则 | 模式 | 档位 | 说明 |
|---|---|---|---|
| R01 未来移位 | `.shift(-n)`（n>0） | 阻断 | 引用未来 K 线 |
| R02 居中滚动 | `rolling(window, center=True)` | 阻断 | 窗口含未来 |
| R03 全局统计回填 | `min()/max()/mean()/std()` 作用于全序列后未按窗口回填 | 阻断 | 用未来统计修正历史 |
| R04 随机切分 | `train_test_split` / `KFold(shuffle=True)`（训练代码） | 阻断 | 时间序列必须按时间切 |
| R05 全局缩放 | `StandardScaler().fit_transform(df)` 全量拟合后切片 | 阻断 | 用测试集统计泄漏进训练 |
| R06 同日成交 | 信号与成交同日（非 `allow_same_day`） | 警告 | 对照铁律 3 |
| R07 截面未来统计 | 横截面排名/分位输入未按决策日切齐 | 警告 | 交给 `cross_sectional.py` 复核 |
| R08 缓存无指纹 | 因子缓存未带数据指纹 | 警告 | 防用过时/未来数据 |
