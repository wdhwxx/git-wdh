### 8.1 H1 修复：run_实盘入口.py 完整重写（301行 → 612行）

**修复前缺陷：**

**修复后能力：**
- 配置加载改用 `ConfigLoader`（YAML/环境变量插值/继承）
- 调用新增的 `create_live_engine()` 一键装配工厂：行情源→券商→持仓→策略→风控→状态→调度

  `--duration`（限时运行）；优雅停止（Ctrl+C 自动保存状态快照）
- 安全：仅真钱实盘模式（trade_mode=live）受交易时段拦截；模拟盘/监控/试运行不受限

### 8.2 H2 修复：LiveEngine 保障组件接线（1459行 → 2148行）

**修复前缺陷：** 引擎全文无任何对 RiskManager/StateStore/Scheduler/Guardian/告警 的引用，
实盘保护机制整体旁路（引擎仅内置简化版资金/仓位检查）。

**修复后接线（全部可选注入，默认自动创建，现有无参调用零破坏）：**

| 组件 | 接线方式 | 生效时机 |
|------|----------|----------|
| RiskManager | 构造函数注入/自动创建；订单提交券商前强制 `check_order`（完整规则库） | 每笔订单 |
| 事件总线 | `start()` 时 RiskManager 订阅数据质量事件；data_feed 挂载实时清洗联动 | 引擎启动 |
| StateStore | `auto_recover=True` 时启动恢复持仓/资金（不生成信号）；定时快照+停止快照 | 启停+周期 |
| LiveScheduler | 引擎自建：巡检（60s）+收盘日报（15:30）+守护巡检+定时快照（300s） | 引擎启动 |
| RiskGuardian | 调度器定期 `evaluate`；PAUSE→风控暂停；强平决策→CRITICAL留痕 | 周期巡检 |
| 监控告警 | 入口层经事件总线联动（AlertManager 默认控制台+日志双通道） | 引擎启动 |

**实盘模式风控增强：** 入口装配工厂按配置映射完整规则库——真钱实盘（trade_mode=live）
自动启用交易时段规则；模拟盘不启用，避免误伤既有模拟脚本。配置映射：
`position`→仓位限制、`risk_control.max_order_value`→单笔限额、`max_daily_trades`→流控、
`max_drawdown_pct`→回撤熔断、`strategy.params`→止损止盈。

**防未来函数保障：** 风控上下文只取"已发生"事实（当前资金/持仓/最新价/峰值资产）；
崩溃恢复仅回写持仓/资金，不生成任何信号；行情时间戳引擎内校验（实时≤now+5s，时间单调）。
