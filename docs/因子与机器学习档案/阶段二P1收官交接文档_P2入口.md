## 3. P2 阶段三项（报告原文 + 验收，引自报告 570-601 行）

### F-13 因子缓存失效解析修复（中｜模块 1 · factor_cache）
- L2 文件名解析改为**结构化解码**（固定分隔或注册表查询），修复因子名含下划线（bollinger_bands 等）导致失效匹配失败的问题。
- 无指纹输入禁止使用「nofp」永久占位，强制要求指纹或缩短 TTL 并显式告警。
- **验收**：含下划线因子名在数据更新后 L2 缓存 100% 失效；nofp 场景日志告警可见。
- 关联：factor_engine/factor_cache 在 P1 全程未动（F-11 回写 #98 已注明「F-13 另行处理」）。

### F-14 增量特征加速与推理缓存（中｜模块 4 · inference_service）
- compute_incremental 接入指标**流式 update 接口**，实现 O(1)/O(窗口) 增量而非每 bar 全量重算。
- 推理结果短 TTL 缓存（跨模块重复调用复用），并接入**延迟基准回归**。
- **验收**：相同历史下增量 vs 全量特征结果一致（容差内）；单 bar 推理耗时不随历史长度增长。
- 关联：F-06 已建 `scripts/推理延迟基准.py` + `myquant/ml/inference_benchmark.py`（蓝图 #93）可直接复用；F-10 的流式 update 接口（ExtremeRegime/Volatility）是接入基础。

### F-15 基本面因子接入（含公告日时点）（中｜模块 1 · 因子引擎 + 数据层 · financial_data）
- financial_data 表新增**公告日（ann_date）**字段与数据回填，查询改为「公告日 ≤ 信号日」的严格时点过滤。
- 基本面因子（PE/PB/ROE/市值）在时点化数据上实现并纳入 factor_validator 门槛。
- **验收**：任何财报值在公告日之前不可见（负向测试）；因子 IC 档案齐全后方可入组合。
- 关联：data_versioner（F-07 时拆出）与 F-15 时点化强相关；报告风险段「数据口径切换」要求历史结论标注数据口径版本。

**Gate 3 口径（报告 629-637 行）**：模拟盘 ≥ 3 个月、扣费后绩效达标、失效监控 0 漏报 → 小额实盘试运行（建议 ≤ 10% 计划资金）。P2 与模拟盘并行。
