### F-10 波动率稳健化 ✅

- **模块**：myquant/indicators/volatility.py（指标层零侵入，features.py/training_pipeline.py 零改动）
- **目标**：低波因子改用 EWMA 波动率（λ 自适应）或稳健估计，叠加极端行情区制标记；波动率因子输出前经去极值管线；验收：股灾/熔断区间内波动率估计相对真实波动偏差收敛、与固定 20 日 std 对比入档（报告 2·因子预处理 F-10 原文）。
- **整改内容**：
  1. `Volatility` 增 `method`（默认 "std" 零变化）："ewma" = RiskMetrics 方差递推 σ²_t = λ·σ²_{t-1} + (1−λ)·r²_{t-1}，λ 两档自适应（常态 0.94 / 极端日 |r|>3σ 降 0.85）；"robust" = 滚动 MAD 稳健估计 σ = 1.4826·median(|r−median(r)|)；批量 + 流式 update 双路径
  2. `Volatility` 增 `winsorize`（默认 False）：输出前 expanding MAD 截断（边界仅含截至 t 历史防未来）；样本 <5 防御不截断；MAD 退化降级 mean±k·std 兜底
  3. 新增 `ExtremeRegime` 指标（output_columns=["regime"]）：滚动绝对收益分位超阈值 → regime 0/1（默认 quantile 0.99）；与 Volatility 隔离可单独启停
- **涉及文件（蓝图已登记#97）**：myquant/indicators/volatility.py
- **新增文件**：tests/unit/test_ml_volatility_robust.py —— **先更新蓝图再创建**（已按 #97 目录树登记先行）
- **验收标准**：股灾/熔断区间内波动率估计相对真实波动偏差收敛；与固定 20 日 std 对比报告入档
- **合规要点**：winsorize 边界/EWMA 递推/rolling 分位全部因果（铁律 11）；F-03 截面整列 winsorize 用于时序特征会引入未来信息故不使用；默认零变化纪律（method="std" / winsorize=False / ExtremeRegime 不注册）
- **实施结果（2026-10-03，蓝图#97）**：
  1. `volatility.py`：Volatility 增 method 三路径（ewma λ 自适应/robust MAD/默认 std 零变化）+ winsorize（expanding MAD clip，mad=0 降级 std 兜底）+ ExtremeRegime 指标；流式 update 同步支持（实盘 O(1)）；_min_periods 按 method 区分（ewma=2）
  2. 新增 `tests/unit/test_ml_volatility_robust.py`（15 项）：std 零变化逐值对拍 / ewma 数值复算与 λ 自适应跳升 / robust MAD 对拍 / winsorize 截断与防未来 / ExtremeRegime 0-1 标记 / 参数防御 / 特征层默认零变化与启用新列 / 流式与批量一致 / 端到端注册 / 验收股灾序列恢复段 MAE 收敛（EWMA < 固定 std）
