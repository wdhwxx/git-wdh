## 二、逐项任务卡

### F-07 模型元数据补全与签名 ✅

- **模块**：myquant/ml/model_registry.py、myquant/ml/training_pipeline.py
- **目标**：① 元数据完整性——补训练数据快照引用、运行环境依赖、常驻绩效（IC/最大回撤）；② 版本溯源——每个 active 模型均可追溯到训练数据快照与环境版本；③ 安全校验——registry 元数据加入 HMAC 密钥签名，加载时先验签名再验 checksum，杜绝"连带重算"式篡改。
- **整改内容**：
  1. ModelVersion 新增 `data_snapshot`（训练数据指纹/行数/起止时间，只登记训练时已得事实）/ `runtime_env`（python/numpy/pandas 版本）/ `model_params_count`（防御式计算）/ 签名三字段（signature/signature_algorithm/signed_at）
  2. 元数据 HMAC-SHA256 签名：密钥=环境变量 `MYQUANT_MODEL_SIG_KEY`（不入库/入 git）；无密钥降级=不签名+跳过校验+告警（默认零变化）
  3. `load_model` 校验顺序 = 签名校验 → checksum 校验；新增 `ModelSignatureError`；`verify_model` 加签名校验
  4. 训练管线：验证集策略最大回撤（常驻绩效 max_drawdown）+ data_snapshot 计算与注册
- **涉及文件（蓝图已登记#94）**：myquant/ml/model_registry.py、myquant/ml/training_pipeline.py
- **新增文件**：tests/unit/test_ml_registry_signature.py —— **先更新蓝图再创建**（已按 #94 目录树登记先行）
- **验收标准**：每个 active 模型均可追溯到数据快照与环境版本；签名被篡改时加载被拒；全量回归零回归
- **合规要点**：data_snapshot 只登记训练时已得数据事实（防未来铁律 11）；签名密钥不得入库/入 git；data_versioner 经用户确认不纳入本次范围（拆 F-15 报告期≠可得时点时点化排期）
- **实施结果（2026-10-03，蓝图#94）**：
  1. `model_registry.py`：ModelVersion 新增 6 字段（to_dict/from_dict 同步，旧 metadata 缺字段默认 None 兼容）；register_model 补全采集（runtime_env 用 importlib.metadata 采集注册时点版本、model_params_count 防御式计算 coef_ 等属性，算不出记 None+告警不阻断）+ 落盘前 HMAC 签名；load_model 先验签名再验 checksum；新增 ModelSignatureError；verify_model 加签名校验
  2. `training_pipeline.py`：新增 _max_drawdown（验证集策略收益方向信号×真实标签的累计净值最大回撤）；evaluate_model 增 compute_drawdown（默认 False 零变化）；run() 计算 data_snapshot 并传入注册 metadata
  3. 新增 `tests/unit/test_ml_registry_signature.py`（18 项）：字段齐全/版本解析/参数量防御/签名往返/密钥缺失降级/元数据篡改被拒/checksum 不回归/retired 不回归/端到端签名链路/旧 metadata 兼容/canonical 稳定/verify 篡改 False/回撤数值对拍等
  4. 验证：py_compile 3 文件 PASS；新增 18 项单测 PASS；全量 pytest = 1897 passed / 2 skipped（基线 1879 + 18，零回归）；git 提交待用户拍板

### F-08 面板切分日历化 ✅

- **模块**：myquant/ml/training_pipeline.py、myquant/ml/features.py
- **目标**：time_series_split 的缓冲从「行数」改为「日历时间」——验证集起点 = 训练集最后时间戳 + horizon 交易日数，适配多标的面板数据；增加跨标的同时间戳分组的确定性归属规则（报告 3·数据划分 F-08 原文）。
- **整改内容**：
  1. 新增 `panel_time_series_split(timestamps, group_ids, ...)`：日历化缓冲（交易日刻度 = 面板数据自身唯一时间戳升序）+ 整组确定性归属（同时间戳样本永不跨 train/valid 边界）；不动现有 time_series_split（单标的零变化）
  2. 新增 `PanelDataset` dataclass + `FeatureEngine.build_panel_dataset(dict[symbol→数据])`：逐标的同口径构建合并，group_ids 记录归属
  3. `run()` 支持 `data: DataFrame | dict[str, 数据]`：dict 自动走面板路径；data_snapshot 增 symbols（仅面板登记）
- **涉及文件（蓝图已登记#95）**：myquant/ml/training_pipeline.py、myquant/ml/features.py
- **新增文件**：tests/unit/test_ml_panel_split.py —— **先更新蓝图再创建**（已按 #95 目录树登记先行）
- **验收标准**：面板数据下，训练集末尾样本的未来 horizon 收益 0% 落入验证集；负向测试覆盖
- **合规要点**：切分只消费面板数据自身时间戳（训练时已得信息，铁律 11 防未来）；缓冲间隔取 horizon+1 交易日 = 与 F-06 单标的实测口径对齐（报告字面"horizon 交易日"隐含 1 根冗余，0% 落入为验收硬标准）
- **实施结果（2026-10-03，蓝图#95）**：
  1. `training_pipeline.py`：新增 panel_time_series_split（日历缓冲 + 整组归属 + 参数防御 + 确定性）；run() 面板入口（dict 自动检测）+ split() isinstance 分支；data_snapshot 增 symbols
  2. `features.py`：新增 PanelDataset + build_panel_dataset（合并/列一致性防御/输入非法防御/全标样本不足防御）
  3. 新增 `tests/unit/test_ml_panel_split.py`（13 项）：整组归属/重复时间戳归属/日历缓冲/日历化非行数/验收核心 0% 落入/负向对照旧语义可检出重叠/参数防御/确定性/面板构建合并与防御/端到端面板注册/单标的零变化
  4. 验证：py_compile 3 文件 PASS；新增 13 项单测 PASS；全量 pytest = 1910 passed / 2 skipped（基线 1897 + 13，零回归）；git 提交待用户拍板
