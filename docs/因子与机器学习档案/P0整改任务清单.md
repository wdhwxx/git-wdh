## 二、逐项任务卡

### F-01 修复训练-推理特征一致性断裂

- **模块**：myquant/ml/inference_service.py、myquant/ml/features.py、myquant/indicators/__init__.py
- **目标**：消除"指标层要求中文列、bars_to_df 产出英文列"导致指标被静默跳过、训练-推理特征集漂移的问题。
- **蓝图事实（已核验）**：指标层与策略层已完成中文列改造（蓝图回写 #1401-1405：`_validate_data` required 改中文、price_col 默认值 close→收盘价、7 个策略文件 df['close']→中文）。因此整改方向为 **ML 层向中文列契约对齐**，而非反向。
- **整改内容**：
  1. `bars_to_df` 输出列改为与指标层一致的中文契约（收盘价/最高价/最低价/开盘价/成交量/成交额），并显式校验
  2. `compute_features` 中指标计算失败从"warning + 跳过"改为**显式抛错 / 写入失败登记**，禁止静默降级
  3. 新增 `feature_contract`（特征签名契约）：训练注册特征签名（列名、顺序、dtype），推理前双向比对，不一致即拒预测
- **涉及文件（蓝图已登记）**：myquant/ml/features.py、myquant/ml/inference_service.py、myquant/indicators/__init__.py
- **新增文件**：myquant/ml/feature_contract.py —— **先更新蓝图 ml/ 段目录树并追加回写记录，再创建**（规则 1.2/2.2）
- **验收标准**：train → register → inference 全链路端到端测试通过；特征列不一致在推理侧 100% 被拦截；全库无静默跳过的指标
- **合规要点**：列名映射属数据契约改动，须同步 `scripts/数据导出_DB到processed.py` 的 CN_COLUMN_MAP 口径（蓝图回写 #1401）；时间序列计算全部 trailing，注释注明数据截至 t 时刻

### F-02 因子有效性校验（IC/ICIR）

- **模块**：myquant/indicators/factor_engine.py、myquant/strategies/multi_factor_strategy.py
- **目标**：为每个因子建立可审计的 IC/ICIR 档案，废除纯手工权重。
- **整改内容**：
  1. 新增 `factor_validator`：IC（RankIC + PearsonIC 双口径，截面-时间双维度）、ICIR、因子收益率、衰减曲线计算
  2. 因子登记表：样本区间、IC 均值、ICIR、胜率、换手、经济逻辑说明；低于门槛自动进入观察/淘汰
  3. `multi_factor_strategy` 权重改为"IC 加权 + 下限约束"
- **涉及文件**：myquant/indicators/factor_engine.py、myquant/strategies/multi_factor_strategy.py、myquant/utils/math_utils.py（复用统计工具）
- **新增文件**：myquant/indicators/factor_validator.py —— **先更新蓝图 indicators/ 段再创建**
- **验收标准**：全部活跃因子均有可审计 IC 档案；权重来源可追溯到因子验证结果；无经济学说明的因子默认不进组合
- **合规要点**：IC 计算只允许使用当前时点及之前已可得数据（严禁用未来收益滚动窗口内的未来信息构造截面）；因子分层回测与全样本一致

### F-03 去极值 + 中性化 + 残差检验

- **模块**：myquant/strategies/multi_factor_strategy.py、myquant/indicators/volatility.py
- **目标**：因子预处理标准化，消除异常值与行业/风格暴露。
- **整改内容**：
  1. 去极值：按因子分布特性自适应（对称分布 MAD 截断；偏态分布分位数截断，如 1%/99%）；禁止对波动率类因子固定 MAD 一刀切
  2. 中性化：行业（申万一级）哑变量 + 对数市值回归取残差
  3. 残差检验：行业/市值暴露显著性（t 值）、残差正态性与异方差检查，超阈值告警
- **涉及文件**：myquant/strategies/multi_factor_strategy.py、myquant/utils/math_utils.py（复用 3σ/四分位检测）
- **新增文件**：myquant/indicators/factor_preprocessor.py —— **先更新蓝图再创建**；行业分类数据需确认数据层来源（蓝图数据层核对后再定）
- **验收标准**：预处理后因子对行业/市值回归 t 值全部不显著；异常值对截面均值影响 < 阈值；检验报告入档
- **合规要点**：中性化回归与去极值统计量均基于截面内当前时点数据计算，禁止引入未来截面信息
- **实施结果（2026-10-03，蓝图#90）**：
  1. 新增 `myquant/indicators/factor_preprocessor.py`：自适应去极值（\|skew\|<0.5→MAD 截断，偏态→1%/99% 分位数截断，波动率类因子不固定 MAD）+ 行业哑变量 N-1/对数市值中性化（numpy lstsq 零 sklearn）+ 残差检验（暴露 t 值、偏度/峰度正态性、残差-拟合异方差，超阈值告警）+ PreprocessReport 序列化报告
  2. `multi_factor_strategy.py` 接入：preprocess_mode（none/winsorize/neutralize/full，默认 none 零变化）+ industry_map 注入 + 调仓现算流通市值（收盘价×流通股本，trailing）+ 报告入档/status 摘要
  3. 行业数据来源确认：本地无行业表，industry_map 可注入（联网 get_stock_list 拉取）；缺省降级仅市值中性化 + 报告披露口径
  4. 验证：py_compile 3 文件 PASS；新增 25 项单测 PASS；全量 pytest = 1814 passed / 2 skipped（基线 1789 + 25，零回归）
  5. 验收口径对照：中性化后暴露 t 值（测试断言 \|t\|<2 通过，test_preprocess_panel_neutralize_full 验证强市值因子残差后 t 不显著）；异常值影响以报告 mean_before/mean_after 均值偏移入档；检验报告随 _last_preprocess_report 入档可审计

### F-04 消除幸存者偏差

- **模块**：数据清洗流水线（myquant/data_access/full_clean_service.py）、myquant/backtest/candidate_pool.py
- **目标**：回测池纳入已退市/长期停牌标的，或明确量化偏差并披露折价。
- **整改内容**：
  1. 回测引入已退市/长期停牌标的的历史行情（akshare 退市股接口或本地归档），股票池按"当时时点是否存续"逐期构建
  2. 无法完整补齐时：计算"存续池回测 vs 全样本池回测"收益差，输出偏差折价系数并在回测报告披露
- **涉及文件**：myquant/data_access/full_clean_service.py（复用 filter_long_suspended_symbols 同口径）、myquant/backtest/candidate_pool.py、config/data_clean_run.json 口径
- **新增文件**：如需退市股数据接入服务，先更新蓝图数据层段再创建
- **验收标准**：回测报告声明口径（是否含退市股）；含偏差折价或完整退市数据，二者必居其一
- **合规要点**：退市/停牌判定只使用当时点已可得数据（ref_date 可注入防未来，沿用 full_clean_service 既有机制）；不得用"今日是否存续"回溯历史池
- **实施结果（2026-10-03，蓝图#91）**：
  1. 新增 `myquant/backtest/survivorship_bias.py`：audit_data_coverage（数据覆盖审计：DB 5589/processed 3195/最新交易日 2026-09-30/停牌近似池/退市覆盖=False 声明）+ estimate_survivorship_discount（偏差折价：2025-01-01~2026-09-30 实测存续池 +27.12% vs 全样本近似 +26.76%，折价 **-0.366%**（年化 -0.145%），口径=停牌风险下界）+ build_point_in_time_pool（逐期存续池，as_of 过滤防未来）
  2. `batch_report.py` 新增可选 data_coverage 参数（默认 None 零变化），HTML 渲染「数据口径声明」节（退市股覆盖/池口径/偏差折价），statement 与数值 HTML 转义防注入
  3. 路径选择：完整退市数据接入需 akshare 沪深退市名单+历史行情（联网依赖、接口未验证）→ 本次走"偏差折价披露"（任务卡二者必居其一满足），逐期池接口已预留，未来退市数据接入无缝生效
  4. 验证：py_compile 3 文件 PASS；新增 15 项单测 PASS；全量 pytest = 1829 passed / 2 skipped（基线 1814 + 15，零回归）；真实 DB 冒烟通过

### F-05 模型失效监控与自动降级

- **模块**：myquant/ml/model_registry.py
- **目标**：失效模型自动检出并降级，杜绝失效模型持续被调用。
- **整改内容**：
  1. 内置失效判定规则：滚动窗口 IC 连续 3 个月低于阈值（初始建议 |IC|<0.02，按市场校准）或绩效回撤超限 → 自动标记失效
  2. 失效模型：从 active 自动切换至上一活跃版本并告警；禁止失效版本被调用
  3. 新版本注册必须"跑赢当前 active"方可激活
- **涉及文件**：myquant/ml/model_registry.py、myquant/ml/training_pipeline.py（注册侧）
- **新增文件**：myquant/ml/model_monitor.py —— **先更新蓝图 ml/ 段再创建**
- **验收标准**：注入低 IC 序列后失效检出并降级时间 < 1 个监控周期；失效版本 0 次被调用
- **合规要点**：监控只消费历史绩效与当前时点状态（无预测性未来信息）；告警走 logging；监控周期参数外置 config（禁止硬编码）
- **实施结果（2026-10-03，蓝图#92）**：
  1. 新增 `myquant/ml/model_monitor.py`：ModelMonitor（失效判定①IC 连续 3 月 |IC|<0.02；②最大回撤超限 20%；单月低→degraded 观察态）+ run() 一次调用内 检出→mark_retired→自动降级→告警（<1 监控周期验收通过）；参数全可注入 + from_config(dict/JSON 路径) 外置 config 通道，默认值常量集中
  2. `model_registry.py`：status 扩展 retired + ModelRetiredError；`load_model(allow_retired=False)` 默认拒绝加载失效版本（**失效版本 0 次被调用**）；`mark_retired` 自动降级到版本号最大的非失效版本（无候选 active 置空），记录 last_retire；`register_model(require_win_gate/win_metric)` 新版本必须跑赢 active 方可激活（默认 False 零变化）
  3. `training_pipeline.py`：evaluate_model 增加 compute_ic（numpy 手写 Spearman 写入 metrics["ic"]）；run() 增加 enable_win_gate/win_metric 透传注册门控（实盘 retrain 建议开启）
  4. 验证：py_compile 4 文件 PASS；新增 27 项单测 PASS；全量 pytest = 1856 passed / 2 skipped（基线 1829 + 27，零回归）；降级演练通过（单次 run() 检出+降级、失效版本加载抛 ModelRetiredError）
