## 四、F-07 任务定义（报告原文）

- **元数据补全**：训练数据快照 ID/指纹、python 与关键库版本、模型参数量、常驻绩效（IC/最大回撤）。
- **签名校验**：registry 元数据加入 HMAC/密钥签名，加载时校验签名后再校验 checksum，杜绝「连带重算」式篡改。
- **验收标准**：每个 active 模型均可追溯到数据快照与环境版本；签名被篡改时加载被拒。
- 报告 L732 备注：新增 `data_versioner`（对应 F-07）——为每次训练登记数据指纹/快照引用，财务表补公告日字段实现「报告期 ≠ 可得时点」的时点化（L421）。**注意**：F-07 核心是 model_registry 元数据补全+签名；data_versioner 是否纳入本次范围需向用户确认（报告将其与 F-07 关联，但也涉 F-15 未来函数时点化，可拆分排期）。
