## 8. 拍板问题清单（D1 决策输入）

1. **方向**：A（放开全市场清洗）or B（维持主板池，回退/降级北交所）？
2. **若 A，补齐范围**：a) 全历史补齐 3,896,184 行（一次性 ~20-35 分钟，派生量完整覆盖）or b) 仅增量补齐近期窗口（历史缺口留存，后续增量滚动补齐）？
3. **若 A，北交所 float_share 策略**：扩展股本数据源（成本高）or 该列对北交所降级 NULL + 披露（推荐先做，低成本）？
4. **若 A，策略口径回归范围**：确认策略消费侧过滤口径；必要时跑一次回测回归（默认只回归鲲鹏壹号/多因子主策略）。
