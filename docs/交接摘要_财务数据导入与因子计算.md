## 三、执行方案

### 第一阶段：财务数据导入数据库

**目标**：将 CSV 文件中的 32.9 万条财务数据导入 `financial_data` 表

**输入**：
- 文件：`datasets/raw/financial/financial_history_20260912.csv`
- 大小：53.7 MB
- 列：symbol, market, report_date, report_type, pe, pb, total_mv, circ_mv, eps, bps, revenue, net_profit, net_profit_parent, roe, gross_margin, debt_ratio, data_source（共17列）

**数据库表结构**（20列）：
```
id (自增主键), symbol, market, report_date, report_type,
pe, pb, ps, total_mv, circ_mv,
revenue, net_profit, net_profit_yoy, revenue_yoy, roe,
gross_margin, debt_ratio, eps, bps, data_source, created_at
```

**字段映射注意点**：
1. CSV 有 `net_profit_parent`，数据库无此列 → 映射到 `net_profit`
2. CSV 无 `ps`、`net_profit_yoy`、`revenue_yoy` → 数据库补 NULL
3. CSV 中 `report_date` 是 `YYYYMMDD` 数字格式 → 需转换为 `YYYY-MM-DD` 字符串
4. CSV 中 `market` 值为 "A股" → 与数据库默认值一致

**现成工具**：
- `myquant/database/queries.py` → `DataQueries.bulk_insert_financial_data(data_list, replace=True)`
- 已实现批量事务插入，支持 REPLACE 模式

**执行步骤**：
1. 在 `scripts/` 目录下新建导入脚本（薄入口，符合治理规则）
2. 读取 CSV → 字段映射 → 日期格式转换 → 构造 dict 列表
3. 分批调用 `bulk_insert_financial_data()`（每批 1 万条）
4. 导入后校验：总行数、抽样 000028 数据、索引确认
5. 更新 `sync_status` 表，记录财务数据同步状态

**预计耗时**：1~2 分钟

### 第二阶段：因子批量计算

**目标**：批量计算技术因子 + 映射基本面因子，写入 `factor_data` 表

**现成工具**：
- `myquant/indicators/factor_engine.py` → `FactorEngine` 向量化因子引擎
- 三级缓存：L1 内存 / L2 磁盘（`cache/factor/`）/ L3 计算
- `myquant/database/queries.py` → `DataQueries.bulk_insert_factor_data()`（待确认是否存在，若无则新建）

**因子分类**：

| 类别 | 因子 | 数据来源 | 计算方式 |
|------|------|----------|----------|
| 技术因子 | SMA(5/10/20/60), EMA, MACD, RSI, BOLL, ATR, ROC, BIAS, KDJ | market_data | FactorEngine 向量化计算 |
| 基本面因子 | PE, PB, ROE, 毛利率, 资产负债率 | financial_data | 直接映射 |
| 量价因子 | 换手率, 成交量比, 涨跌幅 | market_data + circ_mv | 计算 |

**执行步骤**：
1. 确定因子清单（需用户确认）
2. 在 `scripts/` 目录下新建批量计算脚本
3. 技术因子：DB 读行情 → FactorEngine.calculate_batch() → 写入 factor_data
4. 基本面因子：financial_data → 按报告期映射到交易日 → 写入 factor_data
5. 分批处理（按股票分批，控制内存）
6. 计算后校验：覆盖率、异常值、合理性检查
7. 更新 `sync_status` 表

**预计耗时**：10~30 分钟（首次计算）
