## 3. 根因结论

1. **financial_data 为空** = B 类派生量全空的直接根因（数据源缺失，非计算逻辑缺失）。
2. **全量导出缺 turnover 列** = 换手率列不存在的根因（schema 缺陷，与增量列集合不一致）。
3. 下游影响：processed 缺 B 类 → 因子/回测/实盘读不到换手率、流通股本、市盈动、每股收益；且增量写入的换手率在合并时被 reindex 丢弃。
