## P2 中危项（9 项）

### P2-1 · engine「检查-执行」TOCTOU 竞态窗口

| 项 | 内容 |
|---|---|
| 修复文件 | `myquant/live/engine.py`（`_process_signal`/`_risk_manager_check`/`_submit_order` 路径）、`myquant/live/portfolio.py` |
| 症状 | 信号→风控检查→提交 在行情线程，成交回报更新持仓在 broker 线程，跨线程无统一锁；多标的并发信号可能基于陈旧持仓超买 |
| 改法 | 二选一：①给 engine 增加 `_order_lock`（RLock），将「读取 portfolio 检查 → 提交订单」包进同一锁域（锁内不做网络 I/O，broker 提交移出锁外但订单先入暂存）；②信号处理串行化（event_bus 同步分发本已同线程，确认成交回调不并发触发下一信号检查）。建议先确认 data_feed 回调是否单线程串行，再决定加锁粒度 |
| 验证 | ① `pytest tests/unit/test_live_concurrency.py -q` 通过；② 新增 1 个多标的并发信号用例（2 标的同时买入，断言不超最大持仓）；③ dry-run 30 分钟无超买告警 |
